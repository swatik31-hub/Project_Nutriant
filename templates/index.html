ℹ️ About NutriBot

NutriBot is an Agentic AI Nutrition Assistant powered by IBM Granite 13B LLM via IBM watsonx.ai. It collects a detailed user profile and uses multiple built-in AI agents to generate evidence-based, culturally aware, and medically considerate personalized nutrition plans.

ComponentDetail
🤖 AI ModelIBM Granite 13B Instruct v2 (ibm/granite-13b-instruct-v2)
☁️ PlatformIBM watsonx.ai — Sydney region (au-syd)
🧠 Agentic ToolsBMI Calculator · Calorie Estimator (Mifflin-St Jeor TDEE) · Recipe Finder · Q&A Agent
🔒 GuardrailsRegex-based input & output safety filtering on all endpoints
💡 HAM PrincipleHelpful, Accurate, Mindful — enforced in every prompt
🌍 Cultural SensitivityLocation-aware, locally relevant food suggestions
⚕️ Medical SafetyCondition-aware advice + mandatory legal medical disclaimer
🏗️ FrameworkPython 3.x · Flask 3 · ibm-watsonx-ai SDK
🗂️ API EndpointsPOST /api/generate_plan · POST /api/query · POST /api/recipe · POST /api/bmi
🛡️ AI Ethics & Guardrails
  • Input Guardrail — Regex scan on all user inputs before model call
  • Output Guardrail — Regex scan on all model outputs before sending to user
  • HAM Prompting — Every prompt instructs the model to be Helpful, Accurate, Mindful
  • No Medication Advice — Prompts explicitly forbid advising users to stop medication
  • Mandatory Disclaimer — Auto-appended to every nutrition plan
  • Scope Limiting — Off-topic queries are politely redirected
  • Input Validation — Server-side field validation & type checking on all endpoints
⚠️ Medical Disclaimer: NutriBot is an AI system for general informational purposes only. The AI-generated nutrition plans and answers do NOT constitute medical advice, diagnosis, or treatment. Always consult a qualified healthcare professional or registered dietitian before making dietary changes, especially if you have existing medical conditions. Never disregard professional medical advice based on AI-generated content.
